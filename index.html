  • Phrase Hunter

    A phrase-guessing game in the spirit of Hangman, played with the on-screen or physical keyboard.

    Built with
    Object-oriented JavaScript, HTML, CSS animation

About me

I'm James "Breck" Cooper, a software engineer with more than eight years in the industry. Today I'm a senior front-end developer at KnowBe4, where I build security-awareness training that ships in dozens of languages and has to work for everyone, including people using screen readers and right-to-left scripts.

I came to code sideways. Audio engineering taught me to listen for the one thing that's off in a mix, and graphic design taught me to see it. A master's in computer science gave me the tools to fix it. I still work that way: get the details right so the whole thing feels effortless.
